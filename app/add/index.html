Conectar tu repo (solo la primera vez, por dispositivo)

  1. Abre github.com/settings/personal-access-tokens/new
  2. Nombre: nnext-moto · Caducidad: 1 año
  3. Repository access: Only select repositories → elige nnext-moto
  4. Permissions → Contents: Read and write
  5. Generate token → cópialo y pégalo abajo

El token vive solo en este navegador (localStorage), con permiso únicamente sobre tu repo privado nnext-moto.

1. Enlace del anuncio cambiar token

Pega también el texto del anuncio si la web bloquea la lectura automática (Milanuncios, Wallapop…): el sistema rellena los campos con él.

2. Captura (opcional)
